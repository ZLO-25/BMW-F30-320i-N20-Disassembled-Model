# R3–R5 報告：車殼、引擎運轉、螺栓級拆裝（2026-11-12）

## 0. 目標與問題（用我的話重述）

**ZL 的目標**：模擬器要「像真的」，優先順序是 外觀 → 會動 → 手感。R2 OK 之後 ZL 要我一路做完剩下的階段。

**這三個階段各解決一個問題**：

```
  外觀  R3 車殼        問題：車殼是一塊折線擠出的盒子，避震器還穿出引擎蓋
                        └─► 照 ZL 實車照片描輪廓、放樣成曲面，切成可拆的蓋板

  會動  R4 引擎運轉    問題：引擎是靜止的，學員看不到「四行程」怎麼輪流發生
                        └─► 曲軸、活塞、連桿、凸輪、氣門、平衡軸一起轉，加引擎聲

  手感  R5 螺栓級拆裝  問題：點一下就拆掉，沒有「拿工具、鬆螺絲」的過程
                        └─► 拿齊工具 → 按住鬆開每組螺絲 → 讀注意事項 → 取下
```

## 1. R3 車殼

### 做法

```
  ZL 側面照（幾乎正側面）                 ZL 車尾照
  前後輪心距離 = 軸距 2.81 m              總寬 = 1.811 m
        │ 每像素約 3.2 mm                       │ 換算車頂、窗線、肩線的寬度
        ▼                                       ▼
  描出 5 條曲線：車頂中線、肩線、下緣、最寬處半寬、肩線半寬
        │
        ▼
  每隔 5 cm（手機）/ 3 cm（桌機）取一個截面 → 連成一張車皮（截面再用曲線補點，才是圓弧不是折線）
        │
        ▼
  依位置切成 5 塊：車身 / 引擎蓋 / 前保桿 / 後保桿 / 行李廂蓋（各自可拆）
```

| 項目 | 修前 | 修後 |
|---|---|---|
| 外形 | 側面輪廓擠出的盒子 | 照片描邊的曲面車皮，長寬高對得上規格（有測試，誤差 < 1.5%） |
| 引擎蓋、保桿、行李廂蓋 | 另外畫的方塊，和車殼對不上 | 從同一張車皮切下來，縫對得剛好；拆掉引擎蓋看得到葉子板內側 |
| 避震器穿出引擎蓋 | 會 | 不會（前避震器降 4 cm、引擎蓋照照片抬高；有測試） |
| 車殼裡面 | 空的 | 防火牆、通風槽、前避震塔、輪弧內襯 |
| 細節 | 腎型水箱罩、頭燈兩塊方塊 | 門縫、窗框鍍鉻條、後視鏡、門把、頭燈（含天使眼）、腎型水箱罩直柵、M 套件進氣口、L 形尾燈、鯊魚鰭天線 |
| 車色 | 固定深藍 | 檢視工具可選：白（ZL 實車，近似色）/ 藍 / 黑 / 銀 / 紅，會記住 |

外形依據都標成「照片」（`zl_owner_photos_2026`）。照片含車牌，所以沒有放進 repo。

前後對照：`docs/r3/01_side`、`02_front34`、`03_rear34`、`04_hood`（左 = R2、右 = R3，mid 畫質）。

## 2. R4 引擎運轉

在「運轉動畫」分頁選 **引擎運轉：四行程與轉動件**，按「發動」。

```
  曲軸轉兩圈（720°）＝ 每一缸做完一次四行程，四缸各差 180°：

  曲軸角   0°        180°       360°       540°       720°
  1 缸    │ 做功     │ 排氣     │ 進氣     │ 壓縮     │
  3 缸    │ 壓縮     │ 做功     │ 排氣     │ 進氣     │
  4 缸    │ 進氣     │ 壓縮     │ 做功     │ 排氣     │
  2 缸    │ 排氣     │ 進氣     │ 壓縮     │ 做功     │
           ▲ 任何時刻四缸剛好各在不同行程 → 一直有一缸在出力
```

- 會動的：曲軸、四組活塞連桿（真的照曲柄連桿公式算）、兩支凸輪軸與 VANOS（曲軸的一半）、16 支氣門（照行程開關）、兩支平衡軸（兩倍轉速、反向）、減震皮帶盤、飛輪、發電機、冷氣壓縮機。
- **橘光 = 正在做功、藍光 = 正在進氣**；側欄有四缸行程表，顏色一致。
- 轉速 700–7,000 rpm 滑桿（上限是紅線 7,000 rpm，來源 wiki_n20 / bmwtuning_n20）；預設「慢動作 ÷40」，看得清楚活塞與氣門。
- 引擎外殼（缸體、缸頭、氣門室蓋…）與車殼在動畫時自動半透明。
- **聲音**：打勾才出聲。是用瀏覽器即時合成的示意音，音高跟著「點火頻率 = 轉速 ÷ 60 × 2」走，**不是 N20 的錄音**，介面上有寫。

截圖：`docs/r4/01_side.jpg`（側面看活塞：1 缸橘、4 缸藍）、`02_top.jpg`（俯視看凸輪軸與氣門）。

**簡化與待查證（介面上都有寫）**：
- 點火順序 1-3-4-2 是直列四缸常見的順序，**N20 原廠資料還沒查到**。我試著查了，只找到別款 BMW 引擎（N43）寫 1-3-4-2，所以標「待查證」。
- 氣門正時簡化成「整個行程都開著」；實車有重疊角，而且 VANOS / Valvetronic 會一直調。
- 凸輪的角度和氣門開關還沒有逐一對齊（凸輪是示意形狀）。

## 3. R5 螺栓級拆裝

在檢視工具打開 **螺栓級拆裝**。之後拆裝有工具或螺絲資料的零件時，會跳出步驟：

```
  拆下：①拿齊工具 ─► ②按住「鬆開」每組螺絲（放手就歸零）─► ③讀注意事項打勾 ─► ④取下
  裝回：①放回定位 ─► ②按住「鎖上」每組螺絲（反順序）
                       ├─ 有來源的扭力：顯示數字 + 可信度 + 來源連結
                       ├─ 沒來源：寫「待查證」，提醒查原廠資料，不顯示數字
                       └─ 一次性螺絲：要勾「已換新」才能往下
```

- 多顆螺絲會提醒「對角、分次」，標成**通用原則**（一般修車習慣，不是這台車的規格）。
- 導覽、「故意做錯」、「全部裝回」不會跳出步驟，不影響原本的教學流程。
- 預設**關閉**，不改變現有使用方式。

**資料涵蓋率（R5 讓缺口變得很明顯）**：

| | 數量 |
|---|---|
| 可拆零件 | 163 |
| 有工具或螺絲資料、會跳出步驟 | 152 |
| 有螺絲資料 | 45（28%） |
| 螺絲組 | 57 |
| 扭力有可信來源 | **7（12%）**：輪圈螺絲 140 Nm、高壓油泵 12 / 13 Nm、機油濾芯蓋 25 Nm 等 |

照 CLAUDE.md「錯的扭力比沒有更危險」，其餘都是「待查證」。要補齊需要原廠等級的資料（ISTA、Bentley、TIS），見第 6 節。

## 6. 已知問題 / 沒做的

1. **R6（選配：路徑追蹤拍照模式、實車掃描對照、AR/VR）沒有做**：每一項都需要先決定方向（要不要增加 5–20 MB 的資源、要不要用手機掃描），不適合我自己決定。
2. 車殼是照**兩張照片**描的：前臉（頭燈形狀、水箱罩）、車尾的曲面、腰線深淺仍是近似，誤差約幾公分；前臉看起來還不夠像 F30，是最需要再修的地方。補拍正前方、正側面（約 10 m、2–3 倍變焦、相機在車身中間高度）可以再修準。
3. 沒有車內（座椅、儀表板）；ZL 的車窗貼深色隔熱紙，從外面本來就看不太到。
4. 透視模式下輪弧內襯顏色偏深。
5. 點火順序、氣門正時見第 2 節。

## 7. 請 ZL 確認

1. 看 `docs/r3/01_side.jpg`、`02_front34.jpg`，和你的車比：**整體比例、車頂線、前後懸**像不像？哪裡最不像？
2. 檢視工具 → 車色 → 選「白（ZL 實車）」，顏色接近嗎？
3. 運轉動畫 → 引擎運轉 → 發動、打勾聲音，在自己電腦與手機各試一次（看順不順、聲音能不能接受）。
4. 檢視工具 → 打開螺栓級拆裝，拆一個輪子試試「按住鬆開」的手感。
5. 確認 OK 就說「R3–R5 OK」。
