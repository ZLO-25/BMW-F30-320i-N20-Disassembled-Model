# P4 階段回報：整車從外拆到內（傳動、排氣、底盤、煞車、轉向、電系、車身蓋板）

> 日期：2026-10-26。對應 PLAN.md 的 P4 驗收：「整車可以從外拆到內」。

## 一句話

現在零件樹是一整台車：從輪子、保桿、底護板開始，一路拆到副車架、差速器、曲軸，最後只剩車身。測試自動證明手排與自排兩種車都拆得完、裝得回。

## 你的目標，用我的話再說一次

你要教的不只是引擎，而是「一台車怎麼一層一層被拆開」：學員要知道換煞車片前得先拆輪子、拆變速箱前得先放排氣和傳動軸、放前副車架前引擎得吊住。P4 解決的問題是：**把這些「現實上的先後順序」變成模擬器裡真的會擋你的規則**，而不是一句警語。

## 數字從哪來、哪些是示意

- 懸吊形式（前雙關節支柱、後五連桿、電動轉向、後驅）：Wikipedia BMW 3 Series (F30)，community。
- 碟盤直徑、終傳比、電瓶容量、輪圈螺絲扭力、副車架螺絲是否一次性：**全部 null / 待查證**，說明文字裡有寫「（待查證）」。
- `npm run report:verify`：240 個數值，20 個 community、220 個待查證（91.7%）。P7 會回頭查。
- 3D 位置與比例是示意，連桿長度固定，接點對不準是正常的。

## 怎麼測

1. 雙擊 `start-dev.cmd`。車殼切「隱藏」，滾輪拉遠看整台車。
2. 搜「左前煞車碟盤」→ 拆下 → 被卡鉗擋住。依序拆左前輪 → 左前煞車卡鉗 → 左前煞車碟盤。
3. 搜「前副車架」→ 拆下 → 會列出控制臂、拉桿、防傾桿、轉向機、底護板。
4. 搜「八速自排」→ 拆下 → 會說要先拆傳動軸與變速箱橫樑；再試傳動軸 → 要先拆排氣中段。
5. 「檢視工具」→ 子系統清單多了輪胎、前懸吊、後懸吊、副車架、煞車、轉向、傳動、排氣；「只看這個」可以單看煞車。
6. 電腦很卡的話，網址後面加 `?quality=mid`。
7. `npm test`：30 個測試，含「整車拆到只剩車身」兩種變體。
