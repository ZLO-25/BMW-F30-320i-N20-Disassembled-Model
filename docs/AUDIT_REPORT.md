# 真實度查核報告（2026-11-02）：透視白光 + 與實車不符處一次修

## 0. 目標與問題（用我的話重述）

**ZL 的目標**：這個模擬器要拿去教別人，所以 3D 裡每個零件「在哪裡、靠什麼帶動、怎麼拆」都要和真的 F30 320i（N20）一樣；畫面要看得清楚，錯的資料不能進教材。

**這次要解決的問題**：
1. 透視模式的車殼會出現大片白光，把引擎蓋附近的零件蓋掉（U6 之後更明顯）。
2. ZL 問「引擎電腦（DME）位置對嗎？旁邊黏著的是什麼？」→ 旁邊那塊是冷氣濾網，而且**它放錯地方了**。這代表其他零件也可能有同樣問題，所以要先整體查一遍，再一起修，修完再檢視一次。

## 2. 修了什麼（畫面與程式）

- **透視白光**：車漆是金屬度 0.6 + clearcoat 1，攝影棚環境貼圖映在上面的高光在線性空間是很大的數值，乘上 0.1 的透明度還是比 0.5 亮，所以半透明的殼會出現一大片白。現在透視時把車殼改成不反光的霧面（金屬度 0、粗糙度 1、環境反射壓到 0.15、clearcoat 0），切回實體時還原（`PartNode.applyGhostSpecular`）。修前後：`docs/audit/00a–00d`。
- **PR #1 + U6 合併後打包版白畫面**：PR #1 把 drei / three-stdlib 另外分一包，但 U6 的 `@react-three/postprocessing`（在 vendor 包）也用到它們，兩包循環載入，drei 那包拿到的 React 是 undefined（`forwardRef` 錯誤）。拿掉那行分包就好；`npm run e2e` 會抓這種錯。
- `?stats=1` 多一個 `window.__n20cam(px,py,pz,tx,ty,tz)`，自動截圖才有固定視角可以前後比較。
