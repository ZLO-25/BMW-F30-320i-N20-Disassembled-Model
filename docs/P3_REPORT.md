# P3 階段回報：變速箱（手排 GS6-17BG / 自排 GA8HP45）+ 運轉動畫 + 並排對照

> 日期：2026-10-26。對應 PLAN.md 的 P3 驗收：「兩種都能拆；動畫跟文字說明一致；切換後零件樹與步驟跟著變」。

## 一句話

打開就是主畫面，預設自排；上方「手排 / 自排」一按就切換，整個世界（零件樹、拆裝順序、動畫、對照畫面）都跟著走。

## 你的目標，用我的話再說一次

你要的是一個能拿去教別人的「虛擬修車廠」：學員選自己的車是哪種變速箱，然後用同一套拆裝規則，把離合器或扭力變換器一路拆到看得見的程度；看不懂原理時，按一下動畫，看離合器怎麼分離、同步器怎麼先同步再咬合、變換器什麼時候鎖死、每個檔位動力從哪些零件走過。P3 解決的問題是：**同一台車有兩種變速箱，資料和畫面怎麼不打架**。

## 兩種變速箱的拆法（教學用的對照）

```
手排 GS6-17BG                                自排 GA8HP45
──────────────                               ──────────────
排檔桿、離合器總泵（車內 / 防火牆）             油底殼 + 濾網（車底，先放油）
       │                                             │
變速箱總成 ──► 連同 CSC、軸、同步器、撥叉一起下來    變速箱總成 ──► 連同變換器、閥體、油泵一起下來
       │                                             │
壓板（6 顆螺絲，對角鬆）                        驅動盤（撓性盤，鎖在曲軸上）
       │                                             │
離合器片（有方向性，裝回要校正棒）                    （曲軸端到此為止）
       │
雙質量飛輪（鎖在曲軸上，一次性螺絲）
```

共同點：拆到曲軸端那一片（飛輪 / 驅動盤）之前，變速箱一定要先離開。差別：手排的「離合器」是三件乾式零件在引擎上；自排的「離合器」是泡在油裡的離合器包，留在變速箱裡，拆變速箱時整包一起走。

## 怎麼測

1. 雙擊 `start-dev.cmd`。直接進主畫面（預設自排），在上方按**手排**。
2. 車殼切「隱藏」。零件樹往下捲會看到「六速手排變速箱 GS6-17BG」那一大包。
3. 搜尋「壓板」→ 按「拆下」→ 提示「要先拆：六速手排變速箱」，變速箱閃紅。
4. 依序拆：六速手排變速箱 → 壓板 → 離合器片 → 雙質量飛輪。托盤分頁會顯示四個單元（變速箱那包連同 11 個子件）。
5. 「▶ 運轉動畫」→「踩離合器」→ 它會提醒有零件在托盤裡 → 按「全部裝回」→ 拉滑桿看膜片彈簧指與壓環。
6. 「換檔：同步器…」拉滑桿：先看到同步環變紅（摩擦），最後套筒咬住齒輪變綠。
7. 上方切到**自排**（會問要不要清空托盤）。零件樹換成「ZF 八速自排變速箱 GA8HP45」。試拆「驅動盤」→ 被變速箱擋住。
8. 動畫：「扭力變換器」滑桿拉到底看鎖定離合器變綠；「各檔位的動力路徑」按 3 檔 → 表格顯示齒比 2.106 與接合元件 B C E，3D 上對應離合器包變綠。
9. 「⇄ 手排 vs 自排」→ 按 5 檔，上下兩邊同時上色，下方圖例顯示各自的路徑；按 8 檔，手排顯示 N。
10. `npm test`：26 個測試（手排、自排各自「拆到曲軸再全部裝回」）。
