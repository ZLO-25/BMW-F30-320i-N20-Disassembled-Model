# G 階段報告：手排換檔台（G0–G4）

## 目標與問題
讓手排可以「自己換檔」：踩離合器、打檔、給油，看變速箱裡每個零件跟著動。原本的「各檔位動力路徑」動畫只有結果沒有過程，教不出為什麼要踩離合器、同步器在忙什麼、為什麼升檔轉速會掉。

## 做了什麼
```
ShiftPanel.tsx（介面：H 型圖、踏板、轉速條、步驟、挑戰）
      │ 點檔位 → shiftRequest() 立刻回 ok 或拒絕原因；每 125 ms 讀 shiftStatus()
      ▼
animations.ts  manual_shift：每格 stepGearbox → poseGearbox（改幾十個節點的位置與發光）
      ▼
core/gearbox.ts（純邏輯，有測試）：wait_clutch → to_neutral → sync → engage
```
- G0：撥叉修正 3 cm 並分組命名（fork_1_2 / 3_4 / 5_6）；排檔桿加 `stick`。
- G1：`core/gearbox.ts` + 13 項測試（含隨機操作的有限性測試）。
- G2：3D 動畫（排檔桿、撥叉、套筒、同步環、齒輪、倒檔惰輪、離合器、三根軸、飛輪壓板）。
- G3：面板（H 型圖、三組轉速條、離合器 / 煞車按住、油門、自動離合器 / 慢動作 / 引擎聲、步驟清單、拒絕訊息、鍵盤操作）。
- G4：換檔挑戰 5 項（`core/shiftChallenges.ts` + 5 項測試）、e2e 手排段落、文件。

## 怎麼測
`npm test`、`npm run validate`、`npm run build`、`npm run e2e`（含手排換檔：點 1 檔套筒要離開中間、關閉動畫全部回 0）。截圖在 docs/g/。

## 已知問題 / 待確認
1. **齒比仍是示意值**：官方候選值（BMW 新聞稿 2012）因 PDF 在實作環境打不開，沒有核對、沒登記來源。核對後改 `gearbox.ts` 的 `MANUAL_RATIOS`。
2. 倒檔位置（H 型圖 1 檔左邊）與倒檔構造（惰輪滑入）都未經確認，介面有註明。
3. 開發環境是軟體繪圖（1–3 格/秒），換檔手感（約 1.5 秒）與轉速曲線時間常數要在真機感受後再調，常數都在 gearbox.ts 開頭。
4. 官方 5 檔齒比為 1.000，實車可能是直結；模型沒畫這個。
5. 沒做「引擎跟著轉」（曲軸活塞聯動）與小考題（計畫列為視時間）。
