## 一句話

現在可以「點零件就拆」：被擋住會告訴你要先拆誰並把它閃紅；拆下的東西排在托盤上，照反順序點回去就裝好。

## 拆到曲軸的路線（範例）

```
引擎飾蓋 → 考爾 → 氣門室蓋 ─┐
渦輪隔熱板、進氣管、增壓管 → 渦輪 ─┤
增壓管 → 進氣歧管（節氣門一起走）─┤
張緊器 → 兩顆 VANOS ───────────┼─► 缸頭（凸輪軸、氣門等一起走）→ 缸床墊片
冷卻水管 ─────────────────────┘
油底殼 → 機油泵、平衡軸 → 主軸承蓋
活塞連桿（要先拆缸頭、墊片、油底殼）
皮帶 → 減震皮帶盤；VANOS + 張緊器 → 正時鏈 → 導軌
                                   全部完成 ─► 曲軸
```

## 怎麼測

1. 雙擊 `start-dev.cmd`（會自動 `npm install`，因為這次沒有新套件，通常很快）。
2. 車殼切「隱藏」。模式保持「🔧 拆裝」。
3. 直接點氣門室蓋 → 上方出現紅色提示「要先拆：點火線圈」，考爾閃紅。
4. 依序點引擎飾蓋、考爾、氣門室蓋 → 看得到凸輪軸。到「托盤」分頁，先點「點火線圈」→ 會說要先裝回氣門室蓋。
5. 「🛠 檢視工具」→ 爆炸圖拉到底；剖面選「縱切」→ 看得到活塞與曲軸。
6. 想挑戰「拆到曲軸」：照上面的路線圖點；卡住時看提示就知道下一步。最後「全部裝回」。
7. `npm test`：20 個測試，其中一個用真實資料自動跑「全部拆光再全部裝回」。
