## 怎麼測

1. 在專案資料夾 `npm install`，再 `npm run dev`，開 http://localhost:5173
2. 桌機：滑鼠左鍵旋轉、滾輪縮放、右鍵平移。點引擎上的零件 → 右側資訊卡出現；在零件樹搜「渦輪」→ 點選 → 3D 高亮。
3. 手機：`npm run dev -- --host`，用手機開區網網址。一指旋轉、兩指縮放，點零件，下方抽屜切到「資訊」。
4. 車殼切「實體」→ 看得到車的輪廓；切「透視」→ 車殼半透明且不擋點選；「隱藏」→ 只剩引擎。
5. `npm run validate` 應顯示「✓ 資料全部通過」；把 engine.json 任一個 `requires` 改成不存在的 id 再跑一次，應報錯。
