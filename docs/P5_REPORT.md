# P5 階段回報：導覽模式、錯誤示範、學習路徑 Lv1–Lv5

> 日期：2026-10-26。對應 PLAN.md 的 P5 驗收：「新手能照導覽完成一次換火星塞；Lv1 考過 80% 會解鎖 Lv2」。

## 一句話

側欄多了「學習」分頁：五個等級、每級有清單和小考，考過 80% 開下一級；「更換火星塞」等五個導覽會一步一步帶你動 3D，每步寫工具、注意事項、扭力；拆得下來但做法錯的零件（沒鎖正時就鬆凸輪、沒拔電瓶就動方向盤）會先攔下來問你要照正確做還是故意做錯看後果。

## 你的目標，用我的話再說一次

你要的不是一個「會拆零件的玩具」，而是**能帶著一個完全沒碰過車的人，從不知道東西在哪，走到能自己照程序換火星塞**的教材。P5 解決的是「教學順序」的問題：前面四個階段把車做出來了，但學員打開來不知道該先看什麼、該先拆什麼、做錯了會怎樣。所以 P5 做三件事：

```
            學習路徑（該先學什麼）
   Lv1 認識整車 ─► Lv2 各系統 ─► Lv3 怎麼運作 ─► Lv4 動手拆裝 ─► Lv5 故障診斷
      │ 小考 ≥80% 解鎖下一級（設定可關）
      ▼
            導覽（該怎麼做）                    錯誤示範（做錯會怎樣）
   第 1 步 → 第 2 步 → …                    規則上拆得下來
   每步：工具 / 扭力 / 注意                  但沒拿對工具或少做一件事
   remove / install 會真的動 3D             → 攔下來：照正確做？故意做錯看後果？
```

## 做了什麼

| 項目 | 內容 |
|---|---|
| 學習分頁 | Lv1–Lv5 卡片：鎖頭 / 最佳成績 / 這一級要做的事（每件事有「去做」按鈕，直接切透視、只看某系統、播動畫、開導覽）；最下面可關掉解鎖條件、看錯誤紀錄、清除進度 |

## 怎麼測（你自己）

1. 雙擊 `start-dev.cmd`，右側分頁按「🎓 學習」。
2. Lv1 按「考小考（4 題）」，第 2 題會把 3D 的水箱亮起來讓你認。考到 80% 以上，Lv2 的鎖會打開。
3. 想直接看 Lv4：勾「關掉解鎖條件」→ Lv4 →「更換火星塞」→ 開始導覽，照著按「做這一步」「下一步」。
4. 錯誤示範：零件樹搜「轉向柱」→ 拆下。或搜「進氣凸輪軸」，先把前面擋著的東西拆掉，再拆它，會問你有沒有正時鎖定工具。
5. 資訊卡「工具」區點一下 = 拿起來；拿著正時工具再拆凸輪軸就不會被攔。
6. `npm test` 41 個、`npm run validate` 通過。

## 數字從哪來、哪些是示意

- 導覽步驟的扭力值**全部 null / 待查證**（火星塞、考爾螺絲、放油螺絲、濾芯蓋、卡鉗螺絲、輪圈螺絲、電瓶夾），介面寫「請查原廠手冊」。
- 工時（約 40 分鐘等）是示意，不是原廠工時。
- 錯誤的後果文字是通則（任何車沒鎖正時都會跑掉），不是 N20 專屬數據。
- `npm run report:verify`：240 個零件數值，91.7% 待查證（和 P4 一樣，P5 沒加新的規格數字）。
