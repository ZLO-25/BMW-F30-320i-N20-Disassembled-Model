# R1 報告：光與環境（2026-11-12）

## 0. 目標與問題（用我的話重述）

**ZL 的目標**：學員看到的畫面要像「打開真車引擎蓋」看到的東西，優先順序是外觀 → 會動 → 手感。

**R1 要解決的問題**：零件一直「漂浮在黑色太空裡」，金屬反射的是抽象的攝影棚，所以再好的形狀也像示意圖。
R1 只動光線與環境，不需要任何實車資料，改一次全部零件一起受惠。

```
  之前：黑底格線 + 抽象攝影棚反射 ──► 零件像浮在半空、金屬沒有「映著什麼」
  之後：修車廠 ──► 反射裡有一排排日光燈、捲門天光
                 ├─► 水泥地（伸縮縫、油漬）＋ 輪胎與底盤下的接觸陰影 ──► 有重量、站在地上
                 ├─► 拉近時的工作燈 ──► 引擎室深處看得清楚
                 └─► 高畫質：亮反光微微泛光、圓柱邊緣有倒角亮線
```

## 1. 做了什麼

| # | 項目 | 說明 | 畫質 |
|---|---|---|---|
| 1 | 修車廠環境反射 | `src/scene/workshop.ts`：用幾十個方塊做成的小修車廠（12 支日光燈管、捲門天光、氣窗、工具櫃、白板），載入時烘成一張反射圖，取代 three 內建的 RoomEnvironment。不連網、不用圖檔 | 全部 |
| 2 | 背景與地面 | 「修車廠」模式：模糊、調暗的修車廠當背景，40 m 水泥地（程式產生，每 3 m 一道伸縮縫、幾塊油漬，油漬比較亮滑）。「簡潔格線」模式 = 原本的樣子。檢視工具裡切換，會記住（`n20.stage.v1`） | 全部 |
| 3 | 接觸陰影 | 輪胎、底盤正下方那圈柔和的暗影。不每格重畫：拆裝、爆炸圖、顯示設定改變後，停 0.65 秒再畫 2 格 | high / mid |
| 4 | 工作燈 | 跟著鏡頭的聚光燈，離目標 2.4 m 內才亮，越近越亮，像技師拿手電筒 | 全部 |
| 5 | 泛光（Bloom） | 只有很亮的反光（燈管映在鍍鉻、車漆上）會微微泛光 | high |
| 6 | 圓柱倒角 | `cylX/cylY/cylZ` 改成有 1–2 mm 倒角的輪廓旋轉體，邊緣會亮起一圈細線。外形尺寸不變（有測試） | high（半徑 ≥ 8 mm） |
| 7 | 透視車殼 | 修車廠背景是亮的，原本的半透明車殼幾乎看不見，修車廠模式下透明度加倍 | 全部 |

## 4. 已知問題 / 沒做的

1. **車殼本身仍是粗糙的擠出外形**（尤其實體模式），光影變真之後更明顯。這是 R3 的範圍，見下方分析。
2. 實體模式下車殼的平行光陰影邊緣有階梯狀（車殼輪廓本身就是折線），R3 換車殼後會一起變好。
3. 引擎飾蓋沒有替加注蓋留缺口（現在加注蓋位置對了，但被飾蓋蓋住），屬於 R2 引擎室幾何。
4. 修車廠是「像修車廠」的示意場景，不是照片；如果之後想換成真實 HDRI 照片，只要把 `WorkshopEnvironment` 的環境圖換掉。

## 5. 車殼怎麼做最好（不購買授權模型）

```
  選項                         授權乾淨？   像不像 F30   可拆（引擎蓋/保桿）   誰要做事
  ───────────────────────────────────────────────────────────────────────────────────────
  A Sketchfab CC-BY 模型        ✗ 存疑       ★★★★        ✗ 一整塊             ZL 下載
  B 照片描邊 + 官方尺寸自建      ✓ 自己的     ★★★          ✓ 照現有資料分件     我（ZL 補 2 張照片）
  C AI 圖片轉 3D                ✗ 條款不一   ★★           ✗                    –
  D 手機掃描實車                 ✓            ★★★★（形狀） ✗ 一整塊、白車難掃    ZL 拍 100+ 張
```

**推薦 B，D 當選配參考。**理由：

- A 的作者同時上傳大量車款、描述寫「Imported From England」，很像從遊戲拆出來的。拆出來的模型就算標 CC-BY 也不是作者的，放上公開教學網站有風險，而且是一整塊不能拆。
- B 的關鍵條件已經有了：你的 `a70ea229` 側面照幾乎是正側面，前後輪心距離 = 軸距 2.81 m（已有來源），可以換算成每像素約 3.2 mm，把車頂線、窗線、腰線、輪拱描出來；車尾照給寬度與肩線。做成多段截面放樣（loft），引擎蓋、前後保桿、車窗、頭尾燈、後視鏡各自獨立，順便補上防火牆與避震塔（引擎室照片看得到）。
- D 可以之後再做：Pixel 8 Pro 沒有 LiDAR，但照片掃描 App 可以做；白色亮面漆很難掃，比較適合當「實車對照」圖層。

**R3 時請 ZL 再補兩張**：站遠一點（約 10 m）用 2–3 倍變焦拍「正前方」與「正側面」，相機高度在車身中間，可以把透視變形壓到最小。

## 6. 請 ZL 確認

1. 看 `docs/r1/01_high_overview.jpg` 與 `03_high_solid.jpg`：修車廠的亮度、地面樣子可以嗎？要更亮、更暗、還是換顏色（例如環氧樹脂灰綠地板）？
