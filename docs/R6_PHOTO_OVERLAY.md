# R6-B 報告：實車照片疊圖（2026-11-12）

## 0. 目標與問題（用我的話重述）

**ZL 的目標**：模擬器的車要「像真的」。R3 的車殼是照兩張照片描的，但描完之後沒有辦法客觀檢查「到底哪裡不像」，只能用眼睛比。

**這一階段解決的問題**：做一個工具，把實車照片直接疊在 3D 模型上，用同一個視角比對，讓「哪裡不像、差幾公分」看得出來，之後修車殼才有依據。

```
  以前：看照片 ──► 憑印象改模型 ──► 再看照片 ──► 覺得「好像還是不太像」
  現在：照片疊在模型上 ──► 輪廓對不上的地方直接看得到 ──► 照差距改
```

## 1. 怎麼用

檢視工具 → **📷 實車照片疊圖**

```
  ① 選照片            照片只在你的瀏覽器裡，不上傳、不存檔
        │
        ▼
  ② 按照片方向        左側 / 右側 / 正前 / 正後 → 鏡頭水平看過去
        │
        ▼
  ③ 調焦距            預設讀照片 EXIF；裁切過或變焦過要手動調長
        │
        ▼
  ④ 轉動、拉近拉遠、平移鏡頭，讓兩個輪子先對上
        │
        ▼
  ⑤ 切到「差異」      對準的地方變暗，對不上的地方會亮起來
```

微調（縮放、上下左右移、旋轉、左右翻轉）收在「微調照片」裡。調整值會記住，照片不會。

介面截圖：`docs/r6/01_panel.jpg`（疊上 ZL 照片的截圖含拍照環境，只放在專案檔案區，不進 repo）。

## 2. 原理：照片也是一台相機拍的

只要 3D 鏡頭的「視角」和拍照時一樣，鏡頭又擺在拍照的位置，模型就會和照片重疊。

```
                 拍照的手機                          3D 鏡頭
                    ◣ 視角 θ                            ◣ 同一個 θ
                   ╱ ╲                                 ╱ ╲
                  ╱   ╲                               ╱   ╲
                 ╱ 車  ╲                             ╱模型 ╲
  焦距（35mm 等效）──► θ          照片高度 = 畫面高度 ──► 鏡頭用同一個 θ
```

- 35mm 等效焦距是用全片幅對角線（43.27 mm）定義的，所以先算對角線視角，再依照片長寬換成垂直視角。
- 照片放大 N 倍時，鏡頭視角也一起變窄，模型跟著照片一起放大，不會跑掉。
- 暫時取消「顯示照片」時視角不變，模型不會跳。

## 3. 用 ZL 的側面照實測

我用輪心、輪胎接地點、前後保桿最外點，反推 ZL 拍側面照時的位置：

| 項目 | 結果 |
|---|---|
| 相機位置 | 離車身中線約 9.8 m、高度約 0.48 m（蹲低拍） |
| 實際焦距 | 約 **45 mm**（EXIF 記的是 24 mm，照片應該用了 2 倍變焦或裁切過） |
| 畫面中心 | 往下偏約 23%（照片下半部被裁掉，或拍完有裁切） |
| 6 個參考點的誤差 | 平均 2.8 像素（原圖 3072 × 4080） |

把模型照這個位置疊上去：

```
          ╭──────────╮                    ← 車頂、窗線：對得上
   ╭──────╯          ╰────╮
 ▌▌│  ◯               ◯   │▐▐            ← 輪子：對得上（前輪差約 1 cm）
 ↑                         ↑
 模型車頭多出約 10 cm      模型車尾多出約 15–20 cm
```

**結論**：輪距、車頂、窗線都對；**車頭、車尾兩端比照片長**。

可能的原因有兩個，單靠側面照分不出來：
1. **俯視時車頭車尾太方**。真車的保桿從上往下看是圓弧，兩角往後收；模型兩角太寬，從側面看會凸出去。
2. **前後懸比例**。模型的前懸是 0.70 m、後懸是 1.12 m（總長照規格 4.626 m）。

我試過把兩端收窄，但收到側面看起來對時，頭燈、尾燈、保桿下飾板都會穿出車皮，所以這一版**沒有改車殼**，等補拍照片再一起修。

## 4. 需要 ZL 補拍的照片

| 照片 | 怎麼拍 | 用來修 |
|---|---|---|
| 正前方 | 車頭正中間，距離約 8–10 m，2 倍變焦，手機高度和頭燈差不多 | 前臉（最不像的地方）、車頭寬度 |
| 車頭斜上方 | 站在車頭斜前方，手機舉高往下拍 | 車頭俯視時的圓弧（上面的原因 1） |
| 正側面（再一張） | 距離約 10 m，2 倍變焦，手機在車身中間高度、拿正 | 確認前後懸（上面的原因 2） |

拍的時候不需要擋車牌，照片只用在你自己的瀏覽器和這個專案的檔案區，不會放進 repo。

## 6. 已知問題

1. 照片 EXIF 焦距在變焦或裁切後不準，要手動調；面板上有寫。
2. 「上下移」「左右移」同時代表裁切造成的中心偏移，是近似：裁很多的照片邊緣會差幾個像素。
3. 手機上面板會蓋住畫面上半部，可以按「–」縮小。
4. 疊圖不會改變效能（照片是一張 HTML 圖片，不進 3D 場景）。
