# R6-B 報告：實車照片疊圖（2026-11-12）

## 0. 目標與問題（用我的話重述）

**ZL 的目標**：模擬器的車要「像真的」。R3 的車殼是照兩張照片描的，但描完之後沒有辦法客觀檢查「到底哪裡不像」，只能用眼睛比。

**這一階段解決的問題**：做一個工具，把實車照片直接疊在 3D 模型上，用同一個視角比對，讓「哪裡不像、差幾公分」看得出來，之後修車殼才有依據。

```
  以前：看照片 ──► 憑印象改模型 ──► 再看照片 ──► 覺得「好像還是不太像」
  現在：照片疊在模型上 ──► 輪廓對不上的地方直接看得到 ──► 照差距改
```

## 1. 怎麼用

檢視工具 → **📷 實車照片疊圖**

```
  ① 選照片            照片只在你的瀏覽器裡，不上傳、不存檔
        │
        ▼
  ② 按照片方向        左側 / 右側 / 正前 / 正後 → 鏡頭水平看過去
        │
        ▼
  ③ 調焦距            預設讀照片 EXIF；裁切過或變焦過要手動調長
        │
        ▼
  ④ 轉動、拉近拉遠、平移鏡頭，讓兩個輪子先對上
        │
        ▼
  ⑤ 切到「差異」      對準的地方變暗，對不上的地方會亮起來
```

微調（縮放、上下左右移、旋轉、左右翻轉）收在「微調照片」裡。調整值會記住，照片不會。

介面截圖：`docs/r6/01_panel.jpg`（疊上 ZL 照片的截圖含拍照環境，只放在專案檔案區，不進 repo）。

## 2. 原理：照片也是一台相機拍的

只要 3D 鏡頭的「視角」和拍照時一樣，鏡頭又擺在拍照的位置，模型就會和照片重疊。

```
                 拍照的手機                          3D 鏡頭
                    ◣ 視角 θ                            ◣ 同一個 θ
                   ╱ ╲                                 ╱ ╲
                  ╱   ╲                               ╱   ╲
                 ╱ 車  ╲                             ╱模型 ╲
  焦距（35mm 等效）──► θ          照片高度 = 畫面高度 ──► 鏡頭用同一個 θ
```

- 35mm 等效焦距是用全片幅對角線（43.27 mm）定義的，所以先算對角線視角，再依照片長寬換成垂直視角。
- 照片放大 N 倍時，鏡頭視角也一起變窄，模型跟著照片一起放大，不會跑掉。
- 暫時取消「顯示照片」時視角不變，模型不會跳。

## 3. 用官方規格 + ZL 的照片修車殼

ZL 決定不補拍，改用官方規格和現有照片完成。

### 3.1 官方規格（`bmw_press_f30_us_2017`，BMW 新聞稿技術資料，2017 F30 Sedan）

| 項目 | 官方 | R3 模型 | 現在 |
|---|---|---|---|
| 前懸 | 790 mm | 700 | **790** |
| 後懸 | 1,044 mm | 1,116 | **1,044** |
| 車長 | 4,643 mm | 4,626 | **4,643**（測試檢查，誤差 < 1 cm） |
| 軸距 | 2,809 mm | 2,810 | 2,810（不變，差 1 mm） |

```
  R3：  ◄── 後懸 1.116 ──┤◯ 後軸 ……… 前軸 ◯├─ 前懸 0.70 ─►
  現在：  ◄─ 後懸 1.044 ─┤◯ 後軸 ……… 前軸 ◯├── 前懸 0.79 ──►
               縮短 7 cm                         拉長 9 cm
```

輪軸不動，兩端的輪廓照比例拉長或縮短（`bodyShell.ts` 的 `stretchX()`）。後消音器跟著往前移 4 cm，尾管才不會突出保桿。

### 3.2 俯視輪廓：兩端改成圓弧

側面照疊上去之後，模型的車頭、車尾都比照片凸出。原因是 R3 的車頭、車尾從上往下看是方的：兩個角離相機比較近，從側面看就會凸出去。

側面照裡還有一個不受拍照位置影響的線索：「前懸 ÷ 後懸」只量到 0.63，但官方是 0.76。這代表兩端從側面看到的最外點靠近中線，兩角一定是往後收的。

```
  俯視（上 = 車頭）     R3          現在
                    ┌─────┐       ╭───╮      ← 水箱罩在最前面
                    │     │     ╭─╯   ╰─╮    ← 頭燈退後約 6 cm、跟著弧面轉
                    │     │     │       │
                    │     │     │       │
                    └─────┘     ╰───────╯    ← 車尾中間平、兩角收約 16 cm
```

收多少是用側面照疊圖對齊出來的，再拿車頭斜上方照（842052b3）和車尾照（19501054）的保桿弧度檢查。頭燈、水箱罩、進氣口、尾燈、反光片都改成「貼著弧面放」（`endX()` / `endYaw()`），不會穿出車皮。

### 3.3 前臉（正前照 97ee5669，用台灣小客車車牌約 32 cm 寬當比例尺）

- 每個腎型水箱罩約 22 cm 寬、14 cm 高，中間只留一條縫（原本 20 cm）。
- 頭燈改成深灰燈殼加透明燈罩。原本是白色方塊，在白車上看不出來。
- 下進氣口約 56 cm 寬，在車牌正下方（原本 95 cm 太寬），分三段貼著圓鼻。

### 3.4 疊圖驗證（側面照 a70ea229）

我用輪心、輪胎接地點、前後保桿最外點反推拍照位置。結果大約離車 9.1 m、相機高 0.47 m，實際焦距約 42 mm（EXIF 記的是 24 mm，所以照片有變焦或裁切）。6 個參考點平均誤差 2.7 像素。

| | 修改前 | 現在 |
|---|---|---|
| 輪子、車頂、窗線 | 對得上 | 對得上 |
| 車頭 | 模型多出約 18 cm（套官方前懸後） | 差約 3 cm |
| 車尾 | 模型多出約 15 cm | 差約 8 cm |

**限制**：只有一張側面照時，「相機距離」和「焦距」可以互相抵銷（9.1 m + 42 mm 和 9.8 m + 45 mm 一樣對得上輪子）。所以兩端剩下的幾公分分不出是模型還是拍照位置造成的。外形依據仍標「照片」（`zl_owner_photos_2026`），懸長標官方來源。

前後對照：`docs/r6/02_body_front34.jpg`、`03_body_rear34.jpg`、`04_body_top.jpg`（左 R3、右現在）。

## 4. 之後如果要更準

不補拍也能用。以後如果想把剩下的幾公分修掉，最有用的是一張正前方照片（約 8–10 m、2 倍變焦、手機和頭燈同高），和一張從上往下的車頭照。

## 6. 已知問題

1. 照片 EXIF 焦距在變焦或裁切後不準，要手動調，面板上有寫。
2. 「上下移」「左右移」同時用來補裁切造成的中心偏移，是近似的。
3. 手機上面板會蓋住畫面上半部，可以按「–」縮小。
4. 車尾從側面看還比照片多約 8 cm，車尾行李廂蓋的高度也略高（見 3.4 的限制）。
5. 輪距仍是 auto-data 的 1,543 / 1,583 mm。官方 2017 年式是 1,532 / 1,572 mm，差 1 cm，牽動底盤十幾個零件，這次沒動。
