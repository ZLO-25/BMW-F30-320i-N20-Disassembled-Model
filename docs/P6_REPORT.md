## 一句話

側欄多了「🧰 保養」分頁，14 項保養每一項都把**原廠建議**和**台灣保守建議**分開列、各自附來源，可以一鍵在 3D 看位置或開導覽；「學習」的 Lv5 變成 7 個故障情境任務，照「問診 → 判斷 → 拆 → 換 → 裝回」走完，還會提示「下一個該拆誰」；題庫從 20 題補到 54 題。

## 你的目標，用我的話再說一次

前五個階段教的是「車長什麼樣、怎麼拆」。P6 要補的是車主真正會遇到的兩件事：**「什麼時候該保養什麼」**和**「車子出毛病時，怎麼從症狀一路推到要換的零件」**。難處在於資料誠實：保養週期網路上眾說紛紜，你要求不准瞎編，所以這一階段花最多力氣在「哪個數字有來源、哪個沒有」。

## 週期數字從哪來（最重要）

| 項目 | 原廠建議 | 台灣保守建議 |
|---|---|---|
| 機油 | 約 16,000 km 或 12 個月，CBS 會依使用調整 | 原廠的一半，約 8,000 km 或 6 個月（嚴苛使用通則） |
| 空濾（320i） | 約 80,000 km 或 60 個月 | 每次換機油檢查，灰塵多約 16,000–24,000 km |
| 冷氣濾網 | 約 32,000 km 或 24 個月 | 沒有可靠數字：有霉味、風變小就換 |
| 火星塞 | 約 96,000 km 或 72 個月 | 社群建議約 48,000–64,000 km |
| 煞車油 | 第一次 36 個月，之後每 24 個月 | 同原廠，每 2 年 |
| 冷卻液 | 原廠沒有週期 | 約 3 年或 80,000 km（嚴苛使用通則） |
| 自排 ATF | BMW 標「終身」 | ZF 自己建議 8 年或 80,000 km |
| 差速器油 | 原廠沒有週期 | 社群建議約 80,000 km（BMW 通則，非 F30 專屬） |
| 雨刷 | 原廠沒有 | 6–12 個月 |
| 輪胎換位 | 原廠沒有 | 約 8,000–12,000 km（輪胎廠） |

- **原廠欄**來自 BMW 北美的 CBS 參考表（2020 版，英里換算成公里並保留原文）。它是 BMW 的文件，但不是台灣 F30 的手冊，所以標成「社群」可信度，而不是「原廠」。
- **台灣保守欄**找不到台灣官方版本，所以只用有來源的通則；沒有來源的項目（冷氣濾網、皮帶、電瓶、來令片、手排齒輪油）不給數字，只寫要看什麼。
- 手排齒輪油的週期與用量都待查證，只有規格（MTF LT-3，零件型錄）有來源。
- `npm run report:verify` 現在也算保養：289 個數值，46 個社群、243 個待查證（84.1%）。P7 會回頭查。

## 怎麼測（你自己）

1. 雙擊 `start-dev.cmd`，右側分頁按「🧰 保養」，點任一項展開。
2. 按「在 3D 看位置」看零件在哪；按「用導覽帶我做」會跳到學習分頁開始導覽。
3. 上方切「手排」，保養第 9 項會從 ATF 變成手排齒輪油。
4. 「🎓 學習」→ 勾「關掉解鎖條件」→ Lv5 →「怠速抖動、引擎燈閃」→ 開始任務。故意答錯一題看看成績怎麼算。
5. 想挑戰大工程：Lv5 →「冷車啟動咔咔聲」，照「下一個要拆」一路拆到正時鏈。
6. `npm test` 62 個、`npm run validate` 通過。
