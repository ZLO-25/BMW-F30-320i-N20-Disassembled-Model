# F0–F3 報告：四行程燃燒特效（2026-11-15）

計畫：Claude Doc「四行程爆炸火花效果 實作計畫（F0–F4）」。ZL 選「照預設開工」：火焰風格 B（順序與位置照實、亮度與暖色加強）、慢動作點火悶響跟著「引擎聲」勾選框、不做鏡頭震動、F4（爆震、噴油霧）這輪不做。

## 做了什麼

```
每缸相位 φ + 轉速 ──► core/combustion.ts（純邏輯，示意模型，10 個測試）
                          │
                          ▼
           animations.ts 的 fx（每格四缸各算一次，已混合「逐次 / 平均」）
             ├─► 活塞橘光（跟著缸內壓力）
             ├─► CombustionFx（延遲載入）：① 火花 ② 火球 ③ 高溫氣體
             ├─► 面板：點火提前角（示意）、每缸 ⚡ 與壓力條
             └─► engineSound.firePulse()：慢動作每跳火一次一聲悶響
```

| 階段 | 內容 |
|---|---|
| F0 | `src/core/combustion.ts`：提前角、Wiebe 燃燒曲線、已燒體積、燃燒速度、溫度、相對壓力（含下死點前排氣門提早開的洩壓）、`discreteMix`、`averagedGlow`、`sparksBetween`。火星塞整組下移 5 cm（`position.y` 0.09 → 0.04，陶瓷段加長 12 mm 仍插進點火線圈），電極落在燃燒室頂。燃燒室常數集中到 `engineGeom.ts`。 |
| F1 | `src/scene/CombustionFx.tsx`：場景層級群組 `combustion_fx`，兩個 InstancedMesh（氣體圓柱、火花方片）。火球與溫度在片段著色器裡沿視線走 4 / 7 步算出來，邊緣用程式雜訊打散，雜訊種子 = 曲軸角（暫停時火焰也停住）。支援剖面切割。有／無後處理各一組亮度增益。 |
| F2 | `EngineRunPanel`：點火提前角（隨轉速變大）、每缸 ⚡（跳火後 0.45 秒）與壓力條、逐次 / 平均的說明；動畫說明文字改寫（中英）。仍是 125 ms 輪詢。 |
| F3 | e2e 新增燃燒特效檢查、`npm run perf` 前後對照、`?stats=1` 的 `window.__n20crank(deg)`、本報告、CLAUDE.md「F 之後」、DATA_SCHEMA。 |

### 慢動作逐次、一般速度平均

畫面上每秒點火次數 = 轉速 ÷ 30（慢動作再 ÷ 40）：

| 情況 | 每秒點火 | 畫法 |
|---|---|---|
| 慢動作 700 rpm | 0.6 | 逐次：跳火 → 火球長大 → 降溫 |
| 慢動作 3,600 rpm | 3 | 混合 |
| 慢動作 7,000 rpm / 一般速度 | ≥ 4 | 平均輝光（越高轉越亮，帶一點由曲軸角決定的閃爍） |
| 暫停 | — | 逐次（定格看那一瞬間） |
| 系統開「減少動態效果」 | — | 一律平均 |

## 效能（雲端 SwiftShader，個數類是準的，毫秒只能比大小）

靜止畫面（`npm run perf`，沒開動畫，特效不存在）：

| 畫質 | draw call 前 → 後 | 三角形 | 著色器程式 | 貼圖 | 閒置 3 秒畫幾格 |
|---|---|---|---|---|---|
| high | 947 → 947 | 不變 | 55 → 55 | 43 → 43 | 0 → 0 |
| mid | 479 → 479 | 不變 | 23 → 23 | 11 → 11 | 0 → 0 |
| low | 0 → 0 | 不變 | 19 → 19 | 9 → 9 | 0 → 0 |

引擎運轉時（同一個鏡頭，把特效兩個 mesh 關掉前後比）：

| 畫質 | 有特效 | 沒特效 | 差 |
|---|---|---|---|
| L0 | 177 | 175 | +2 |
| L1 | 179 | 177 | +2 |
| L4 | 718 | 714 | +4（AO 那一趟會再畫一次） |

打包：特效自己是延遲載入的 chunk `CombustionFx`（gzip 3 KB），只有點開「引擎運轉」才下載。**首包 `index` gzip 151 → 154 KB（+3 KB）**，沒有做到計畫寫的「首包不變」：燃燒模型被運轉動畫（首包）用到，加上中英說明文字。要省可以把模型搬進延遲 chunk，代價是活塞橘光晚一格、架構變複雜，我判斷不值得。

## 哪些數字是示意、哪些有來源

| 數值 | 狀態 |
|---|---|
| 點火提前角（怠速約 13°、紅線約 26° BTDC） | **示意**：由「燃燒持續角度 × Wiebe 50% 點 − 8°」算出，教科書的最佳扭力點火經驗法則 |
| 燃燒持續 40°–65°、Wiebe a = 5、m = 2 | **示意**（教科書常用值） |
| 壓力曲線、溫度、火花放電 1.5 ms | **示意** |
| 壓縮比 10 | 有來源：`bmw_st1111_n20` p.5（10.0:1） |
| 缸徑 84 mm | 有來源：`wiki_n20` |
| 點火順序 1-3-4-2 | **仍待查證**。ST1111 PDF 在 archive.org，這次雲端連不到（proxy 403），沒辦法翻 |

介面上提前角、壓力條旁都標「示意」，說明文字寫明是教科書模型。沒有登記任何新來源。

## 已知問題 / 需要 ZL 確認

1. **FPS 要實機看**：雲端沒有顯示卡。請在手機與桌機開 `?bench=1`，再開「引擎運轉」看一下。
2. **後處理開關的亮度不完全一樣**：L3 以上（有 AO）火焰在線性空間相加，比 L0–L2 稍暗；已經用不同增益補償到接近，見 `f1_quality_levels.jpg`。
3. **活塞頂偏白**：上死點附近燃燒室只有 1.5 cm 高，火焰疊在淺色活塞頂上，看起來偏白。從側面看最清楚（`f1_four_moments.jpg` 的角度）。
4. **接觸陰影**重畫時會把特效也畫進去（它用 overrideMaterial 畫整個場景）。特效在引擎裡面、被缸體擋住，實際上看不出差別。
5. 點火悶響是 Web Audio 合成的示意音效，不是錄音；只在慢動作逐次畫法、而且「引擎聲」勾著的時候出現。
6. 沒動到：自排、手排換檔台、拆裝邏輯、載入流程、其他五個動畫。
