# R2 報告：引擎室寫實化（2026-11-12）

## 0. 目標與問題（用我的話重述）

**ZL 的目標**：學員打開引擎蓋看到的，要和真車「一眼對得上」：東西在哪裡、長什麼樣、用什麼固定。

**R2 要解決的問題**：R1 把光變真之後，引擎室裡「位置不對」和「形狀太像方塊」的地方反而更明顯。
對照 ZL 的引擎室俯視照，發現最大的錯是**空濾盒放在副水箱的位置**，而且整個引擎室缺少螺栓、管束這些「真的東西才有」的細節。

```
  ZL 引擎室照片 ──► 對照模型 ──► 找出差異
                               ├─ 位置錯：空濾盒、副水箱（大錯，學員會學錯）
                               ├─ 形狀太示意：引擎飾蓋、空濾盒
                               └─ 缺細節：螺栓頭、管束、波紋管
                                      │
                                      ▼
                        照照片重畫 ＋ 標記「這個形狀依據什麼」
```

## 1. 做了什麼

| # | 項目 | 修前 | 修後 | 依據 |
|---|---|---|---|---|
| 1 | 空濾盒 | 方盒，放在引擎室右前角 | **車頭中間、水箱上方的 T 字形盒**：灰色下殼＋黑色上蓋、肋條、金屬扣、前方進氣口、右後出口 | ZL 引擎室照片 |
| 2 | 副水箱（新零件 `eng.cooling.expansion_tank`） | 沒有 | **引擎室左前角**：半透明白色殼、看得到藍綠色冷卻液、MIN/MAX 刻線、黑蓋＋橘色警告標、水管與管束 | ZL 引擎室照片 |
| 3 | 引擎飾蓋 | 平板 | 圓角面板、亮面上層、鋁色字條、斜紋、圓形徽章（不放 BMW 標誌），**右前缺口讓機油加注蓋露出來** | ZL 引擎室照片 |
| 4 | 進氣管 | 直線 | 從空濾盒右後出口繞到渦輪進氣口，有波紋環、兩端管束 | 照新的空濾盒位置重畫 |
| 5 | 連接件 | 圓柱代替螺栓 | 氣門室蓋螺栓改成**有凸緣的六角螺栓頭**；冷卻水管 4 端加**管束**；點火線圈加線束管 | 一般零件外形 |
| 6 | 外形依據欄位（新） | 沒有 | 每個零件可以標「示意 / 照片 / 掃描 / CAD」，資訊卡會顯示，非示意要附來源 | 路線圖建議的 `shapeConfidence` |

教學資料也跟著改：「檢查冷卻液」導覽前兩步、保養「冷卻液」的焦點零件都改指向副水箱（之前沒有這個零件）。

### 外形依據怎麼看

```
  資訊卡最下面多一行：
  ┌───────────────────────────────────────────┐
  │ 外形依據：照片（依 ZL 實車照片）  ← 綠框   │  photo / scan / cad
  │ 外形依據：示意                    ← 一般   │  schematic（預設）
  └───────────────────────────────────────────┘
```

目前標「照片」的有 3 個：引擎飾蓋、空濾盒、副水箱。其他 162 個仍是示意（濾芯在盒子裡、照片看不到，所以也標示意）。


多的大多是管束與波紋環。low 會自動退成簡單形狀。

## 4. 已知問題 / 沒做的

1. **實體模式下，避震器上座會穿出引擎蓋**（R1 就有，不是 R2 造成的）。車殼是 R3 的範圍，換車殼時一起修。
2. **磨損與髒污（路線圖 M1）還沒做**：零件都還是新的樣子。要做的話建議當 R2b，和「標籤貼紙」一起。
3. 只重畫了照片看得清楚的 3 個大件；電瓶線、保險絲盒、各種感知器接頭仍是示意。
4. 副水箱的確切高度與管路走向是從單張俯視照推估，側面看可能偏差幾公分。

## 5. 請 ZL 確認

1. 看 `docs/r2/01_bay_top.jpg`，和你拍的引擎室俯視照比：**空濾盒的大小、副水箱的位置**對得上嗎？
2. 副水箱的顏色（半透明白殼、藍綠色冷卻液、橘色蓋標）和你車上的一樣嗎？如果你的冷卻液是別的顏色，告訴我。
3. 確認 OK 就說「R2 OK」。下一步建議 **R3 車殼**（會一起修掉避震器穿出引擎蓋），需要你補拍正前方、正側面各一張（站遠約 10 m、2–3 倍變焦、相機在車身中間高度）。
